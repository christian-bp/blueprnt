description: How the AI assistant fills in a role's purpose and responsibilities, and why you always review it first.

Writing a role's purpose and responsibilities from scratch takes time. An AI
assistant can draft both from what you have already entered about the role,
so you have something to start from instead of a blank field.

## Where it appears

The assistant is available wherever a job profile is being written: in the
"New role" dialog that opens from "Create role" while creating a new role,
and in the job profile's edit mode on an existing role's page. Choose
"Draft job profile with AI" to open it.

## Generating a draft

The assistant drafts from the role's title, function, team, and track,
whichever of those you have filled in so far. You can optionally add a short
free-text description to steer the draft further. If a new role has no title
yet, the assistant states that it needs one first rather than generating
something ungrounded.

## Review before you save

A generated draft only fills the purpose and responsibilities fields you are
currently editing; it never saves anything by itself. Review and edit the
draft, then choose "Save" (or "Create role" for a new role) to keep it.
Closing the form without saving discards the draft entirely.
